系统简介

一鱼快速构架-XStart

基于XPHP框架开发，包含用户模块和简易后台。适用于快速开发小型网站应用。

演示：http://xstart.xphp.net

技术栈
Bootstrap v5.x jQuery v3.x bootstrap-notify XPHP v6.1.x
前台功能
  • 首页展示：系统简介，关于页面
  • 用户模块：登录，注册，修改资料，修改密码，退出
后台功能
  • 用户管理：添加，修改，删除，启用，停用
  • 网站配置：添加，修改，删除，生成配置
  • 菜单管理：添加，修改，删除
  • 数据备份：备份，还原，下载，删除
仓库：https://gitee.com/xphpnet/xstart
