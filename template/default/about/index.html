一鱼快速构架-XStart

基于XPHP框架开发，包含用户模块和简易后台。适用于快速开发小型网站应用。

演示：

http://xstart.xphp.net

构架：

  • Bootstrap v3.4.1
  • jquery v3.7.1
  • layer_mobile v2.0
  • XPHP v6.1.x

安装：

  • 未安装时跳转安装界面，一键安装。

前台：

  • 首页展示：系统简介，关于页面
  • 用户模块：登录，注册，修改资料，修改密码，退出

后台：

  • 用户管理：添加，修改，删除，启用，停用，修改等级
  • 网站配置：添加，修改，删除，生成配置文件
  • 菜单管理：添加，修改，删除，启用，停用
  • 数据备份：备份，还原，下载备份，删除备份
仓库：https://gitee.com/xphpnet/xstart
