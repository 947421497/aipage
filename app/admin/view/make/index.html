快速生成
命令生成
  • 生成表：php xphpcli make:table admin@test test
  • 生成控制器：php xphpcli make:ctrl admin@test _cp
  • 生成模型：php xphpcli make:model admin@test id _def
  • 生成列表模板：php xphpcli make:view admin@test index index
  • 生成添加模板：php xphpcli make:view admin@test add add
  • 生成修改模板：php xphpcli make:view admin@test edit edit
开发流程
设计数据表 —> 生成表 —> 生成MVC —> 添加菜单 —> 完善模板 —> 完善模型 —> 完善控制器
开发示例

如建立数据表结构：app/admin/command/make/table/test.tpl

CREATE TABLE `aphp_test` (
`id` int(11) unsigned NOT NULL AUTO_INCREMENT COMMENT 'ID',
`title` varchar(100) NOT NULL DEFAULT '' COMMENT '标题',
`content` text NOT NULL COMMENT '内容',
`sort` int(11) unsigned NOT NULL DEFAULT '0' COMMENT '排序',
`update_time` int(10) unsigned NOT NULL DEFAULT '0' COMMENT '更新时间',
`status` tinyint(1) unsigned NOT NULL DEFAULT '0' COMMENT '状态',
PRIMARY KEY (`id`)
) ENGINE=InnoDB AUTO_INCREMENT=1 DEFAULT CHARSET=utf8mb4 COMMENT='测试表';
一键生成MVC后，在 菜单管理 中添加菜单：test/index，再进一步完善模板模型和控制器。
