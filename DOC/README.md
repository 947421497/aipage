## 📋 文档内容概述

### 1. 架构文档 (architecture.md)

架构文档深入讲解了框架的内部设计和实现原理。文档包含 MVC 架构的详细说明、请求生命周期的完整流程、核心组件的职责划分等内容。通过类图和流程图直观展示了框架各组件之间的关系。安全机制部分介绍了 SQL 注入防护、XSS 防护、CSRF 防护等安全措施的实现方式。适合希望深入理解框架原理的开发者阅读。

### 2. 数据库文档 (database.md)

数据库文档详细描述了系统的数据表设计。文档包含用户表、菜单表、配置表等核心表的完整表结构定义。字段说明部分详细介绍了每个字段的数据类型、默认值、业务含义。ER 关系图展示了表之间的关联关系。文档还提供了初始化数据的 SQL 语句和扩展表设计的建议。进行涉及数据库的业务开发时，应参考此文档。

### 3. 模板语法 (template.md)

模板语法文档是视图开发的完整参考手册。文档详细介绍了模板引擎的各种语法，包括变量输出、条件判断、循环遍历、模板包含、模板布局等功能。丰富的代码示例演示了每种语法的使用方法。文档还介绍了内置函数和过滤器的使用方法，以及如何开发自定义过滤器。进行前端页面开发时，此文档是必备参考。

### 4. 开发文档 (development.md)

开发文档提供了详细的开发实践指导。文档涵盖开发规范、编码约定、控制器开发、模型开发、视图开发、中间件开发等各个方面。代码生成器部分详细介绍了如何使用命令行工具快速生成 MVC 代码。调试指南部分提供了常见问题的排查方法和解决方案。是进行实际项目开发的主要参考文档。

### 5. 项目依赖 (dependencies.md)

项目依赖文档列出了框架运行所需的全部依赖项。PHP 扩展依赖部分说明了每个扩展的作用和安装方法。数据库依赖部分指定了 MySQL 的版本要求和字符集配置。前端资源部分详细介绍了 Bootstrap、jQuery、图标库等前端组件的使用方式。服务器环境要求部分提供了 Nginx 和 Apache 的配置说明。是部署和运维的重要参考文档。

### 6. 快速开始 (quickstart.md)

快速开始文档专为新手开发者设计，提供了一步一步的入门指导。文档从开发环境准备开始，涵盖了安装部署、基础配置、目录结构介绍、代码生成使用等完整流程。常见问题排查部分汇总了开发过程中可能遇到的典型问题和解决方法。附录部分的部署清单提供了生产环境部署的检查要点。

### 7. 迁移文档 (MIGRATION_remove_score_money.md)

迁移文档记录了项目的重要变更历史。当前版本记录了移除积分（score）和余额（money）字段的详细说明。文档包含迁移前检查清单、具体的数据库 ALTER TABLE 语句、代码修改建议等内容。还提供了回滚脚本以应对迁移后发现的问题。
